# VeriNews – Fake News Detection System

An Information Retrieval (IR) mini project that classifies a news article as **Real** or **Fake** using text preprocessing, TF-IDF vectorization (Vector Space Model) and Logistic Regression, served through a Flask web app.


## Quick start (everything is already trained)

This package already contains the dataset, `model.pkl`, `vectorizer.pkl` and the evaluation results, so you only need:

```bash
pip install -r requirements.txt
python app.py          # or double-click run.bat (Windows) / ./run.sh (Mac, Linux)
```
Open http://127.0.0.1:5000 and paste any article (`sample_articles.txt` has six ready-made examples).
To retrain from scratch at any time, run `python model.py` (takes 1–3 minutes).

## Project explanation

The system treats each article as a document in a vector space. Words are cleaned and reduced to stems, each document becomes a weighted TF-IDF vector, and a linear classifier learns which terms separate real reporting from fake news. At prediction time the same pipeline is applied to the pasted text, and the model's coefficients are used to show which words pushed the result.

## Working flow

1. User pastes an article and clicks **Detect News**.
2. JavaScript validates the input and sends it to `POST /predict`.
3. Flask preprocesses the text and transforms it with the saved TF-IDF vectorizer.
4. Logistic Regression returns `P(fake)` and `P(real)`.
5. The server returns label, confidence, top keywords and every preprocessing stage.
6. The UI renders the result card, keyword chips, preprocessing accordion and adds a row to the session history.

## Algorithm

1. **Load data** – label Fake = 0, Real = 1; merge title + text; drop empty and duplicate rows.
2. **Remove leakage** – strip the `CITY (Reuters) -` prefix from real articles, so the model cannot cheat on that tag.
3. **Preprocess** – lowercase → remove punctuation → tokenize → remove stop-words → Porter stemming.
4. **Split** – 80% train / 20% test, stratified.
5. **TF-IDF** – `tfidf(t,d) = (1 + log tf) × log(N / df)`, max 50,000 terms, L2-normalized. Each document is a vector in the Vector Space Model.
6. **Train** – Logistic Regression: `P(real|d) = σ(w·x + b)`.
7. **Evaluate** – accuracy, precision, recall, F1 and confusion matrix on the test set (saved to `assets/`).
8. **Explain** – contribution of a term = `coefficient × tf-idf weight`; the largest absolute values are shown as keywords.

## API

`POST /predict` with `{"text": "..."}` returns `label`, `confidence`, `probabilities`, `keywords`, `preprocessing`.
Errors return `{"error": "..."}` with status 400 (bad input) or 503 (model not trained).

## Advantages

- Fast, lightweight and trainable in minutes on a laptop.
- Transparent: shows influential keywords and every preprocessing step.
- Uses core IR concepts directly (tokenization, stemming, TF-IDF, VSM).
- Responsive UI with session history; no database or external API required.

## Limitations

- Learns writing style and vocabulary of the 2016–2017 US-centred Kaggle dataset, not factual truth.
- Bag-of-words ignores word order, sarcasm and context.
- May generalize poorly to other topics, languages or newer events.
- Very high test accuracy reflects dataset similarity; real-world accuracy will be lower.
- No fact-checking against external sources.

## Future scope

- N-grams, BM25 weighting, or word embeddings / transformer models (BERT).
- Cosine-similarity retrieval of similar verified articles.
- Source credibility and URL analysis; multilingual support.
- Persistent history with user accounts, model retraining from feedback, Docker deployment.
